# Stela Nexus Neural 💬

Projeto de Inteligência Artificial focado em **conversação inteligente, factual e contextualizada**. A Stela não inventa respostas; ela busca informações precisas e mantém memória do diálogo para uma interação natural.

##  Funcionalidades Principais

-   **Conversação Factual:** Responde perguntas baseando-se estritamente em contextos fornecidos ou bases de conhecimento, evitando alucinações.
-   **Memória de Curto Prazo:** Lembra das últimas interações para manter a coerência do diálogo.
-   **Processamento de Linguagem Natural:** Utiliza modelos transformers avançados para entender nuances da linguagem humana.
